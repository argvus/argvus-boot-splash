# Справка

Техническая справка о том, что устанавливает пакет и какие значения он использует.

## Что вы получаете

| Компонент | Описание |
| --- | --- |
| Логотип Argvus | Центрированная метка, нарисованная над надписью |
| Надпись | Текст `ARGVUS` под логотипом |
| Индикатор прогресса | Тонкая полоска, ширина которой соответствует прогрессу загрузки Plymouth |
| Диалог ввода пароля | Запрос LUKS с полем для скрытого ввода (`•` точки) |
| Появление | Заставка появляется примерно за 1 секунду при запуске Plymouth |
| BMP UKI | `argvus-uki-splash.bmp` для UKI / загрузок на основе systemd-boot |

Название пакета `argvus-boot-splash`, и он заменяет более старый пакет
`argvus-plymouth`, если тот был установлен.

## Установленные файлы

В каталоге `/usr/share/plymouth/themes/argvus/`:

| Файл | Размер | Назначение |
| --- | --- | --- |
| `argvus.plymouth` | — | дескриптор темы (имя, описание, модуль) |
| `argvus.script` | — | скрипт темы (собственный язык скриптов Plymouth) |
| `argvus-logo.png` | 256x256 | логотип, RGBA |
| `argvus-text.png` | 400x53 | надпись, RGBA |
| `progress-bar.png` | 400x4 | заполненная часть индикатора прогресса |
| `progress-bar-track.png` | 400x4 | незаполненная дорожка |
| `entry-box.png` | 400x48 | поле ввода пароля |
| `entry-line.png` | 300x2 | правило/подчеркивание поля пароля |
| `bullet.png` | 12x12 | скрытый символ |
| `logo-glow.png` | 260x300 | изображение свечения логотипа |
| `argvus-uki-splash.bmp` | 400x400, 32-бит | битовая карта заставки UKI/systemd-boot |

Плюс лицензия в `/usr/share/licenses/argvus-boot-splash/LICENSE`.

## Метаданные пакета

| Поле | Значение |
| --- | --- |
| Имя | `argvus-boot-splash` |
| Архитектура | `any` |
| Зависимости | `plymouth` |
| Дополнительные зависимости | `mkinitcpio`, `dracut` |
| Конфликты / заменяет | `argvus-plymouth` |
| Лицензия | GPL-3.0-only |

## Цвета

| Элемент | Цвет |
| --- | --- |
| Фон | `#111316` |
| Акцент (логотип, словесный знак, заполнение прогресса) | `#3590BD` |
| Трек прогресса | `#262933` |
| Текст запроса пароля | светло-серый с голубым оттенком (`#B8C4CE`) |

Тема использует сплошной тёмный фон на любом разрешении, поэтому она никогда
не переключается автоматически между светлой и тёмной версиями.
